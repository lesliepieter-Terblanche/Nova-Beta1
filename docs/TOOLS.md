# Tool reference

_Generated by `python scripts/gen_tool_docs.py` — every ability Nova's model can call._

🔒 = asks you to confirm (yes/no) before running.

## System & PC control

Always available.

| Tool | What it does | Parameters |
|---|---|---|
| `get_time` | Get the current date and time. | — |
| `open_app` | Open an application on the PC. | `name` |
| `open_url` | Open a website in the default browser. | `url` |
| `system_status` | CPU, memory, disk, battery and GPU status of the PC. | — |
| `take_screenshot` | Take a screenshot of the PC screen and send it to the user's phone. | — |
| `look_at_screen` | Look at what is currently on the PC screen and answer a question about it (uses Gemini vision). | `question`? |
| `look_at_image` | Look at an image file (photo, screenshot, scan) and answer a question about it (uses Gemini vision). | `path`, `question`? |
| `read_clipboard` | Read the text currently on the clipboard. | — |
| `copy_to_clipboard` | Put text on the clipboard. | `text` |
| `run_shell` 🔒 | Run a PowerShell command on the PC and return its output. Use for tasks no other tool covers. | `command` |
| `power_action` 🔒 | Lock, sleep, restart or shut down the PC. | `action` |
| `cancel_shutdown` | Cancel a pending restart or shutdown. | — |
| `set_reminder` | Set a reminder. Nova will say it out loud and message the user's phone at that time. | `text`, `when` |
| `list_reminders` | List upcoming reminders. | — |
| `cancel_reminder` | Cancel a reminder by its id (see list_reminders). | `reminder_id` |

## Memory & 2nd brain

Offered to the model when you say things like: _remember, memory, memories, forget, note, notes, brain, journal, recall, what do you know, do you know, did i_

| Tool | What it does | Parameters |
|---|---|---|
| `remember` | Permanently remember something the user tells you to remember. | `text`, `kind`?, `important`? |
| `recall` | Search permanent memory and the notes vault for anything related to the query. | `query` |
| `correct_memory` | Correct a memory that is wrong or out of date. The old version is kept in history. | `memory_id`, `corrected_text` |
| `write_note` | Create or add to a note in the 2nd brain vault. | `title`, `content`, `folder`? |
| `read_note` | Read a note from the vault by (part of) its title. | `title` |
| `list_notes` | List the most recently changed notes. | `folder`?, `limit`? |
| `journal` | Add an entry to today's journal / daily log. | `entry` |
| `ingest_to_brain` | Save a web page or document into the 2nd brain so it can be searched later. | `source`, `title`? |
